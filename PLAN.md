# The Program

Six training days: Push / Pull / Legs, run twice a week, plus a Sunday mobility session you can do at home.
_Italic entries are warm-ups and cool-downs._

| Day | Exercise | Machine | Primary | Sets × Reps |
|---|---|---|---|---|
| **Mon** — Push A - Chest, Front Delts, Side Delts, Triceps, Abs | _Incline Walk + Cuff & Empty-Bar Prep_ | Treadmill + Cable Station - low pulley, D-handle + Empty Barbell | mobility | 7-8 min |
|  | Barbell Bench Press | Barbell + rack, flat bench, safety pins set just BELOW chest touch height | chest | 3 × 6-10 |
|  | Dumbbell Bench Press - flat | Adjustable Dumbbells + flat bench | chest | 3 × 8-12 |
|  | Pec Deck Fly | Pec Deck Machine | chest | 2 × 10-15 |
|  | Seated Dumbbell Shoulder Press | Adjustable Dumbbells + upright bench | front delts | 3 × 8-12 |
|  | Cable Lateral Raise (2 sets per side) | Cable Station - low pulley, D-handle | side delts | 4 × 12-15 |
|  | Rope Triceps Pushdown | Cable Station - high pulley, rope | triceps | 3 × 10-15 |
|  | Overhead Cable Triceps Extension | Cable Station - low pulley, rope | triceps | 2 × 10-15 |
|  | Kneeling Cable Crunch | Cable Station - high pulley, rope | abs | 2 × 12-20 |
|  | _Rack-Upright Chest + Triceps Stretch_ | Squat Rack Upright + Foam Roller | mobility | 6-8 min |
| **Tue** — Pull A - Lats, Upper Back, Rear Delts, Traps, Biceps, Forearms, Lower Back, Neck | _Rower + Scapular Activation_ | Rowing Ergometer + Cable Station - high pulley, rope | mobility | 8-9 min |
